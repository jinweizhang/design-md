Do's 与 Don'ts

要做

纯平涂双色
食指贴齐左缘
  • 两枚图标成对出现,同尺寸、同描边权重
  • 保持「陶土 = 动作,近黑 = 结构」的配色规则
  • 悬停用底板 + 环形阴影,glyph 颜色不变
  • 新增同族图标先落到 R=7.5 与 2px 描边上
  • 所有端点 round,圆角不小于 1.45

不要做

渐变 + 投影
食指居中(歧义手势)
  • 不要加渐变、投影、外发光或任何 3D 体积暗示
  • 不要在浅色底上把陶土提亮成 Coral(仅 2.96:1)
  • 不要引入冷灰,中性色必须带黄棕底调
  • 不要把食指画在手掌中部——剪影会读成不雅手势
  • 不要只靠颜色传达状态,需同时配文案或对勾
