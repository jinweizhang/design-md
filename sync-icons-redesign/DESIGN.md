# 同步图标设计规范 —— Claude 设计语言

自动同步 / 手动同步 两枚图标的扁平化重设计。视觉语言继承自
[Claude (Anthropic) DESIGN.md](https://getdesign.md/claude/design-md):暖陶土色、
纯暖色中性、无渐变、无重投影。

---

## 1. 视觉主题与氛围

**一句话主题:温暖、克制、手绘感的双色扁平图标——像一本好书里的插图,而不是一块发光的塑料。**

原图标是蓝色渐变 + 高光 + 3D 立体手指,属于典型的“科技感拟物”风格:光泽、体积、
冷色调。Claude 的设计语言恰好站在它的反面——**暖羊皮纸底色、陶土色点缀、纯平涂、
零渐变**。因此重设计的核心动作是三个“去除”和一个“建立”:

- **去渐变**:所有蓝色线性渐变改为单一平涂色值。
- **去体积**:删除高光、内阴影、投影,图形回到纯剪影。
- **去冷色**:蓝色系(`#3B82F6` 一类)整体置换为陶土色 `#c96442`,中性色全部带黄棕底调。
- **建立配对关系**:两枚图标共用同一套 24 网格、同一套描边权重与圆角逻辑,
  并用**同一条配色规则**(陶土 = 动作,近黑 = 结构)绑定成一个家族。

**关键特征**

- 24 × 24 网格,2px 安全边距,主几何基于 R=7.5 的基准圆
- 双色平涂:陶土 `#c96442` + 近黑 `#141413`,不使用第三种色相
- 圆头端点(`stroke-linecap: round`)——呼应 Claude “不用锐角”的柔和主张
- 箭头/涟漪为实心三角与圆弧,不描边、不叠加效果
- 层级只靠**色彩对比**表达,不靠阴影

## 2. 配色与角色

### 语义 Token

| Token | 浅色主题 | 深色主题 | 角色 |
| --- | --- | --- | --- |
| `--ico-1` 动作色 | Terracotta `#c96442` | Coral `#d97757` | 承载“同步动作”的元素:领先箭头、食指、点按涟漪 |
| `--ico-2` 结构色 | Near Black `#141413` | Warm Silver `#b0aea5` | 承载“结构/主体”的元素:回程箭头、手掌与拇指 |
| `--ico-plate` 底板 | Warm Sand `#e8e6dc` | Dark Surface `#30302e` | 悬停/按下时出现的圆角底板 |
| `--ico-ring` 光环 | Ring Warm `#d1cfc5` | `#3d3d3a` | Claude 式 `0 0 0 1px` 环形阴影 |
| `--ico-done` 完成 | Sage `#6b7d55` | Sage Light `#8fa176` | “已同步”成功态 |
| `--ico-off` 禁用 | Stone Gray `#87867f` | Olive Gray `#5e5d59` | 禁用态(双色合并为单色) |

### 配色规则(两枚图标共用)

> **陶土色 = 正在发生的动作;近黑 = 承载动作的主体。**

- 自动同步:领先的那支箭头是陶土色,回程箭头是近黑——形成循环的“一推一收”。
- 手动同步:食指与涟漪是陶土色(人正在触发),手掌与拇指是近黑(主体)。

这条规则让两枚图标的**陶土面积大致相当**,并排摆放时视觉重量平衡,不会一枚抢戏。

### 对比度校验(WCAG 非文本图形要求 ≥ 3:1)

| 前景 | 背景 | 比值 | 结论 |
| --- | --- | --- | --- |
| Terracotta `#c96442` | Ivory `#faf9f5` | **3.70:1** | 通过 |
| Terracotta `#c96442` | Parchment `#f5f4ed` | **3.54:1** | 通过 |
| Terracotta `#c96442` | Warm Sand `#e8e6dc`(悬停底板) | **3.12:1** | 通过 |
| Near Black `#141413` | Ivory `#faf9f5` | **17.50:1** | 通过 |
| Sage `#6b7d55` | Ivory `#faf9f5` | **4.25:1** | 通过 |
| Stone Gray `#87867f` | Ivory `#faf9f5` | **3.47:1** | 通过(禁用态本可豁免) |
| Coral `#d97757` | Near Black `#141413` | **5.90:1** | 通过(深色主题动作色) |
| Warm Silver `#b0aea5` | Near Black `#141413` | **8.29:1** | 通过(深色主题结构色) |

> **注意:Coral `#d97757` 在 Ivory 上仅 2.96:1,不达标。**
> 因此浅色主题的悬停态**不能**把陶土提亮成珊瑚色。悬停通过“加暖沙底板 + 暖色光环”
> 表达,glyph 颜色保持不变——这同时也更贴近 Claude “靠底色位移而非变色”的做法。

### 关于 Sage 绿

Claude 的 DESIGN.md 提到插图使用 “terracotta、black 和 muted green” 但未给出绿色色值。
`#6b7d55` / `#8fa176` 是在该描述下补充定义的暖调橄榄绿,已校验双主题对比度。
这是本规范对原体系的**唯一扩展**。

## 3. 字体排印规则

图标本身不含文字,以下为其配套标签的规范(与 Claude 体系一致):

| 角色 | 字体 | 字号 | 字重 | 行高 | 字距 |
| --- | --- | --- | --- | --- | --- |
| 图标标题(卡片) | Anthropic Serif → Georgia | 20.8px | 500 | 1.20 | normal |
| 图标标签(列表/按钮) | Anthropic Sans → system-ui | 16px | 500 | 1.25 | normal |
| 辅助说明 | Anthropic Sans → system-ui | 14px | 400 | 1.43 | normal |
| 状态徽标 | Anthropic Sans → system-ui | 12px | 500 | 1.25 | 0.12px |

中文回退字体栈:`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。
标题若使用衬线,中文回退 `"Songti SC", "Noto Serif CJK SC", serif`。

**原则**:标签用无衬线(功能性),卡片标题可用衬线(编辑感)。图标标签**不要**全大写——
中文无大小写,且 Claude 的小字仅在 12px 以下才加字距。

## 4. 组件样式

### 4.1 绘制网格

| 参数 | 值 |
| --- | --- |
| 画布 | 24 × 24 |
| 安全边距 | 2px(实际内容落在 3.5 – 20.5) |
| 基准圆 | 圆心 (12, 12),半径 **7.5** |
| 主描边 | **2px**,`round` 端点与连接 |
| 次描边(涟漪) | **1.5px**,`round` |
| 最小圆角 | 1.45(拇指)—— 不存在锐角 |

### 4.2 自动同步 `sync-auto`

两支首尾相接的箭头构成闭合循环 = 无需人介入的持续同步。

| 元素 | 几何 | 颜色 |
| --- | --- | --- |
| 领先弧 | R=7.5,角度 180° → 40°(顺时针扫过顶部),2px 圆头 | `--ico-1` |
| 领先箭头 | 等腰三角,底宽 5.2,长 4.0,底边切于弧末端 | `--ico-1` |
| 回程弧 | 领先弧绕圆心旋转 180°(0° → 220°) | `--ico-2` |
| 回程箭头 | 同上,旋转 180° | `--ico-2` |

两段弧各占 140°,余下两处 40° 缺口正好由箭头填入——所以循环闭合但不粘连。

```

<path d="M15.75 8.85L20.32 10.24L19.74 5.51Z"/>
<path d="M19.5 12 A7.5 7.5 0 0 1 6.25 16.82" stroke-width="2" stroke-linecap="round" fill="none"/>
<path d="M8.25 15.15L3.68 13.76L4.26 18.49Z"/>
```

### 4.3 手动同步 `sync-manual`

食指点按 + 两道涟漪 = 由人触发的一次性同步。

| 元素 | 几何 | 颜色 |
| --- | --- | --- |
| 外涟漪 | 圆心 (10.45, 9.0),R=4.8,142° → 38°,1.5px | `--ico-1` |
| 内涟漪 | 同圆心,R=2.6,150° → 30°,1.5px | `--ico-1` |
| 食指 | 圆角矩形 (8.8, 9) 3.3 × 8,r=1.65,**绘制在手掌之上** | `--ico-1` |
| 指节 | 圆 (14, 14) r=1.75、(16.3, 14.8) r=1.65 | `--ico-2` |
| 手掌 | 圆角矩形 (8.8, 13.8) 9.2 × 7.4,r=3 | `--ico-2` |
| 拇指 | 圆角矩形 (6.3, 14.6) 2.9 × 5.8,r=1.45,旋转 -22° | `--ico-2` |

三个关键决策:

1. **食指必须与手掌左边缘对齐(同为 x=8.8)。** 若食指落在手掌中部,剪影会读成不雅手势——
   这是初版实测踩到的坑。
2. **右上角两个指节圆**制造阶梯状轮廓,这是让纯色块读成“手”而非“blob”的关键。
3. **食指用陶土色压在近黑手掌之上**,既打散了大面积黑色块,又让“正在按下的那根手指”
   成为视觉焦点。

### 4.4 状态

底板尺寸 = 图标尺寸 + 12px 内边距,圆角 12px(Claude “generously rounded”)。

| 状态 | 底板 | glyph | 其他 |
| --- | --- | --- | --- |
| 默认 | 无 | `--ico-1` / `--ico-2` | — |
| 悬停 | Warm Sand `#e8e6dc` | **不变** | 环形阴影 `0 0 0 1px #d1cfc5` |
| 按下 | Warm Sand | **不变** | `inset 0 0 0 1px rgba(20,20,19,.15)`,`scale(.96)` |
| 聚焦 | 无 | 不变 | 环形阴影 `0 0 0 2px #3898ec`(Claude 体系中唯一的冷色) |
| 同步中 | 无 | 不变 | 自动:整体 `rotate` 1.4s 线性循环;手动:涟漪 `opacity` 1.2s 脉冲 |
| 已同步 | 无 | 双色合并为 Sage `#6b7d55` | 可替换为对勾图标 |
| 禁用 | 无 | 双色合并为 Stone Gray `#87867f` | `cursor: not-allowed` |

**动效**:统一 `160ms ease-out`。`prefers-reduced-motion: reduce` 时,旋转与脉冲
降级为静态(不得移除状态本身,仅移除位移)。

## 5. 布局原则

### 间距体系

基准单位 4px,比例尺:`4 · 8 · 12 · 16 · 24 · 32 · 48`。

| 场景 | 尺寸 |
| --- | --- |
| 列表行内图标 | 20px |
| 按钮内图标 | 20px,与文字间距 8px |
| 卡片主图标 | 48px |
| 空状态插图 | 64px |
| 底板内边距 | 12px |
| 图标与标签垂直间距 | 16px |
| 双栏面板中缝 | 1px `#f0eee6` 分隔线,两侧各 48px |

### 尺寸阶梯

`16 · 20 · 24 · 32 · 48 · 64`。**16px 为下限**——再小则手部指节会糊成一团,
此时应改用纯箭头图标替代手动同步图标。

### 留白理念

图标是“插图”而非“字形”,四周留白应显著大于图标本身的内部空隙:卡片场景下,
48px 图标周围至少留 32px 净空,让它像书里的插图一样有呼吸。

## 6. 层级与投影

| 层级 | 处理 | 用途 |
| --- | --- | --- |
| L0 平面 | 无底板、无阴影 | 默认态图标 |
| L1 底板 | Warm Sand `#e8e6dc`,圆角 12px | 悬停/按下 |
| L2 光环 | `0 0 0 1px #d1cfc5` | 悬停 |
| L3 内嵌 | `inset 0 0 0 1px rgba(20,20,19,.15)` | 按下 |
| L4 轻托 | `rgba(0,0,0,.05) 0 4px 24px` | 承载图标的卡片(图标本身不加) |

**投影哲学**:图标本体**永远不加投影**。原图标的蓝色光晕与立体高光被完全移除——
Claude 用环形阴影和底色位移表达深度,而不是用光。深度属于容器,不属于图形。

## 7. Do's 与 Don'ts

### 要做

- 两枚图标始终成对出现、同尺寸、同描边权重——它们是一个家族。
- 保持“陶土 = 动作,近黑 = 结构”的配色规则,换主题时只换 token 不换规则。
- 所有端点使用 `round`;新增元素的圆角不得小于 1.45。
- 悬停用底板 + 光环表达,glyph 颜色保持不变。
- 新增同族图标时,先落到 R=7.5 基准圆和 2px 描边上再调细节。
- 手动同步图标的食指必须贴齐手掌左边缘。

### 不要做

- **不要**给图标加任何渐变——这是与原设计最根本的分歧点。
- **不要**加投影、外发光、高光或任何 3D 体积暗示。
- **不要**在浅色底上把陶土提亮成 Coral `#d97757`(仅 2.96:1,不达标)。
- **不要**引入冷灰——所有中性色必须带黄棕底调。
- **不要**引入第三种色相(Sage 仅用于“已同步”状态)。
- **不要**在 16px 以下使用手动同步图标。
- **不要**把食指画在手掌中部——剪影会读成不雅手势。
- **不要**只靠颜色区分状态:“已同步”除了变绿,还应配文案或对勾。

## 8. 响应式行为

| 断点 | 图标尺寸 | 布局 |
| --- | --- | --- |
| < 479px | 24px | 双栏面板塌陷为上下两行,中缝分隔线转为横向 |
| 479 – 767px | 32px | 单列,图标与标签横向排列 |
| 768 – 991px | 40px | 双栏恢复,中缝保留 |
| ≥ 992px | 48px | 双栏,两侧各 48px 净空 |

### 触控目标

图标的可点击区域必须 **≥ 44 × 44px**,与图标视觉尺寸解耦:20px 图标也要有 44px 命中区
(用透明内边距撑开,不要放大图标本身)。

### 收缩策略

- 双栏面板 → 垂直堆叠,中缝竖线改为 1px 横线 `#f0eee6`。
- 图标逐级降档 48 → 40 → 32 → 24,**不做非整数缩放**(避免 2px 描边在非整数倍下发虚)。
- 标签在最窄断点从图标下方移至图标右侧,节省垂直空间。

### 可直接使用的提示词

- “在 24×24 网格上画一枚自动同步图标:圆心 (12,12)、半径 7.5 的基准圆,上弧从 180° 顺时针
  扫到 40°,2px 圆头描边,用 Terracotta (#c96442);末端接一个底宽 5.2、长 4.0 的实心三角箭头。
  下弧是上弧绕圆心旋转 180° 的副本,用 Near Black (#141413)。不要渐变,不要投影。”
- “在 24×24 网格上画一枚手动同步图标:近黑 (#141413) 的手掌为圆角矩形 (8.8,13.8) 9.2×7.4 r=3,
  右上角叠两个指节圆让轮廓呈阶梯状;拇指为旋转 -22° 的圆角矩形。食指用 Terracotta (#c96442)
  圆角矩形 (8.8,9) 3.3×8 r=1.65,**左边缘与手掌对齐**并绘制在手掌之上。指尖上方加两道
  1.5px 陶土色涟漪弧。纯平涂。”
- “给这两枚图标做悬停态:加一块 Warm Sand (#e8e6dc)、圆角 12px 的底板,外加
  `0 0 0 1px #d1cfc5` 环形阴影,glyph 颜色保持不变。过渡 160ms ease-out。”
- “把这套图标切到深色主题:动作色换成 Coral (#d97757),结构色换成 Warm Silver (#b0aea5),
  背景 Near Black (#141413)。其余几何不变。”

### 迭代指南

1. 一次只改一枚图标,改完立刻把两枚并排渲染检查视觉重量是否仍然平衡。
2. 引用色名而非“调深一点”——说 “Terracotta (#c96442)”,不说 “橙色”。
3. 任何新颜色上线前先算对比度,图形类元素门槛 3:1。
4. 手部类图标必须在 20px 和 16px 下各看一遍剪影,确认没有糊成色块或产生歧义手势。
5. 描述阴影时使用 “环形阴影 `0 0 0 1px`”,不要说 “drop shadow”。
