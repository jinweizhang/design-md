# 爆款视频 AI 生成 · 设计规范（Claude 设计语言）

本规范基于仓库中的 Claude DESIGN.md（羊皮纸底色、陶土强调色、衬线标题、环形阴影、无渐变），针对微信小程序场景和“积分付费”业务做了落地调整。所有 Token 与 `index.html` 中的 `:root` 一一对应。

## 1. 视觉主题与氛围

- 关键词：温暖、克制、可信。它是一个“帮你赚钱的工具”，不是一个“炫技的 AI 玩具”。
- 底色用羊皮纸（Parchment），不用纯白；卡片用象牙白（Ivory）叠一层，靠明度差而不是阴影区分层级。
- 陶土色只出现在“下一步要做的事”上：主按钮、价格、选中态、进度。一屏最多一个陶土色实心按钮。
- 视频缩略图在原型阶段统一用“单字 + 暖色块”的字标占位（衬、包、护…），避免假图片干扰评审，也让卡片节奏一眼可读。

## 2. 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--pa` Parchment | `#f5f4ed` | 页面底色 |
| `--iv` Ivory | `#faf9f5` | 卡片、底部 Dock、TabBar |
| `--wh` White | `#ffffff` | 输入框、需要“可点”暗示的浮起卡片 |
| `--sand` Warm Sand | `#e8e6dc` | 次按钮、图标底、进度轨道 |
| `--ink` Near Black | `#141413` | 标题、深色 Toast、邀请卡 |
| `--char` Charcoal | `#4d4c48` | 正文 |
| `--olive` Olive Gray | `#5e5d59` | 辅助说明（在象牙白上 6.3:1） |
| `--stone` Stone Gray | `#87867f` | 仅用于占位符、划线原价（3.5:1，不承载信息） |
| `--bc` / `--bw` / `--ring` | `#f0eee6` / `#e8e6dc` / `#d1cfc5` | 分隔线 / 描边 / 环形阴影 |
| `--brand` Terracotta | `#c96442` | 图形元素：进度条、图标、选中描边 |
| `--brand-strong` | `#ae5230` | 主按钮底色、价格文字、Tab 选中 |
| `--brand-ink` | `#9a4526` | 品牌浅底上的文字（徽标，5.17:1） |
| `--brand-soft` | `#f3e3da` | 品牌浅底（“AI 识别中”“生成中”徽标） |
| `--ok` / `--ok-soft` | `#56693f` / `#e6e9dc` | 已完成、到账 |
| `--err` / `--err-soft` | `#b53333` / `#f5e2dd` | 失败、删除、校验错误 |
| `--warn` / `--warn-soft` | `#83570f` / `#f2e8d3` | 排队中、提示 |
| `--focus` | `#3898ec` | 仅键盘/无障碍焦点环 |

为什么要多一个 `--brand-strong`：Claude 原版陶土色 `#c96442` 上放象牙白文字，对比度只有 3.70:1，达不到正文 4.5:1。按钮是这个产品最关键的文字，所以按钮底色加深到 `#ae5230`（4.92:1），原陶土色保留给不承载文字的图形。同理，`--brand-strong` 放在 `--brand-soft` 浅底上只有 4.15:1，所以徽标文字再深一档用 `--brand-ink`。

## 3. 字体

| 层级 | 字体 | 字号 / 字重 / 行高 |
| --- | --- | --- |
| 页面大标题 `.h-page` | 衬线（Noto Serif SC / 宋体） | 28 / 500 / 1.2 |
| 区块标题、弹窗标题 `.h-sec` | 衬线 | 20 / 500 / 1.25 |
| 卡片标题 `.h-card` | 无衬线（PingFang / Noto Sans SC） | 16 / 600 / 1.35 |
| 正文 `.t-body` | 无衬线 | 15 / 400 / 1.6 |
| 说明 `.t-cap` | 无衬线 | 13 / 400 / 1.45 |
| 注脚 `.t-mic` | 无衬线 | 12 / 400 / 1.4 |
| 数字 `.num` | Georgia + 等宽数字 | 余额、价格、进度百分比 |

- 衬线只给“有情绪的话”：首屏口号、页面标题、结果页“充值成功”。按钮、表单、列表一律无衬线。
- 衬线只用 500 字重，不加粗。

## 4. 组件

- 按钮：高 50（主）/ 44（中）/ 36（小），圆角 14 / 12 / 10。主按钮 `--brand-strong` 实心；次按钮 Warm Sand + 1px 环形阴影；文字按钮 Olive；危险按钮 Crimson 实心，只在确认删除时出现。
- 不可用按钮：Warm Sand 底 + Stone 字，不做半透明。
- 卡片：象牙白、1px `--bc` 描边、圆角 16，不加投影。
- 列表：分组列表，行高约 52，左侧 32×32 Sand 图标底，右侧 Stone 箭头。
- 输入框：白底、1px `--bw` 描边、圆角 12；右上角字数计数；错误时 Crimson 描边 + 3px 浅红外环 + 下方原因文字。
- 徽标：高 22 胶囊，状态四色（排队 warn、生成中 brand、完成 ok、失败 err），配 13px 线性图标。
- 底部面板（Sheet）：圆角 24、顶部把手、右上关闭；遮罩 `rgba(20,20,19,.45)`。
- 弹窗（Dialog）：宽 300，标题衬线，两个按钮等宽，危险操作右侧为 Crimson。
- Toast：Near Black 胶囊，四种类型只靠左侧图标区分；错误 Toast 例外用 Crimson 底。
- 底部 Dock（`.footer.dock`）：象牙白 + 上描边，底部留 34px 给 Home Indicator。

## 5. 布局

- 画布 390×812；状态栏 47、导航栏 44（右侧预留 87×32 小程序胶囊）、TabBar 84。
- 页面左右边距 20；卡片内边距 16；区块间距 18–24；间距基于 4 的倍数。
- 一级页面（创作、作品、我的）用左对齐衬线大标题；二级页面用 17px 无衬线导航标题 + 返回。
- 视频卡片固定 9:16 比例双列，左上角画幅、右下角时长，卡片底部“标题 + 积分 + 使用”。

## 6. 层级与深度

| 层级 | 做法 |
| --- | --- |
| 0 页面 | Parchment |
| 1 卡片 | Ivory + 1px 描边 |
| 2 可点浮起 | White + 1px 环形阴影 |
| 3 面板 / 弹窗 | Ivory + 遮罩 |
| 4 Toast | Near Black |

不使用渐变和大投影；唯一的例外是骨架屏的微光。

## 7. 该做与不该做

该做：
- 金额永远写清“扣多少、从哪扣、扣完剩多少”（赠送池优先，其次充值池）。
- 每个失败都给原因 + 下一步 + 积分去向（“已全额返还”）。
- 空态给一句解释 + 一个主操作 + 一个示例。
- 付费触点写收益（“去水印导出，再做 3 条同款”），不写功能名。

不该做：
- 不在陶土色 `#c96442` 上放白色小字。
- 不用 Stone 灰写任何需要读懂的信息。
- 不在一屏放两个陶土色实心按钮。
- 不用 emoji 或彩色插画当图标，图标统一 1.7px 线性、圆角端点。

## 8. 响应式与平台

- 以 iPhone 13/14（390 宽）为基准；小屏 375 时双列卡片宽度自适应，文字不缩小。
- 点击热区不小于 44×44；底部固定操作区避开 Home Indicator。
- 遵守小程序胶囊安全区：导航栏右侧 110px 内不放可点元素。
- 深色视频播放页（05b）用 Near Black 底 + 象牙白文字，胶囊和返回键切换为浅色。
