# 爆款视频 AI 生成 · 设计规范（Apple 深色模式）

本规范按 `skills/ui-designer` 的 9 节格式编写，锚定仓库所指向的 Apple DESIGN.md（[getdesign.md/apple](https://getdesign.md/apple/design-md)）：纯黑画布、SF Pro、唯一彩色是 Apple Blue、界面本身后退。这是小程序工具界面，所以用深色模式的表面分层，而不是官网那种大幅产品摄影。

所有 Token 与 `index.html` 的 `:root` 对应。`export/preview.html` 由同一份 Token 渲染。

## 1. 视觉主题与氛围

一句话：**纯黑、精确、安静的工具**。产品是视频，界面只负责把下一步指出来。

- 页面是纯黑 `#000000`。卡片、列表、输入框用更亮一档的灰抬起来，不用投影。
- 标题用 SF Pro Display，600 字重，负字距。没有衬线。
- 整个界面只有一个彩色：Apple Blue。它只出现在可点的东西上：主按钮、链接、价格、选中、进度。
- 绿、红、橙只表示状态（完成、失败、排队），不拿来装饰。
- 视频封面在原型里用深灰块加白色单字，播放键是白圆黑图标。

| `--surface` | `#1c1c1e` | 卡片、列表、Dock |
| `--wh` | `#2c2c2e` | 输入框、浮起内容 |
| `--sand` | `#3a3a3c` | 次按钮、图标底、进度轨道 |
| `--sand2` | `#636366` | 次按钮按下、分段控件选中 |

### 文字

| Token | 色值 | 角色 | 对比度 |
| --- | --- | --- | --- |
| `--ink` | `#f5f5f7` | 标题、主文 | 19.3（对纯黑） |
| `--char` | `#ebebf5` | 正文 | 14.4（对 `#1c1c1e`） |
| `--olive` | `#98989d` | 辅助说明 | 5.9（对卡片） |

| `--iv` | `#ffffff` | 蓝色按钮上的字、播放键 | — |

### 强调色

| Token | 色值 | 角色 |
| --- | --- | --- |
| `--brand-strong` | `#0071e3` | 主按钮底。白字对比度 4.70 |
| `--brand-pressed` | `#0066cc` | 主按钮按下。白字 5.57 |
| `--brand` | `#2997ff` | 深底上的链接、价格、Tab 选中、进度。对卡片 5.64 |

`#0a84ff` 是 iOS 深色模式的系统蓝，但白字只有 3.65，所以实心按钮不用它，改用官网的 `#0071e3`。链接放在黑底上时用更亮的 `#2997ff`，不用按钮蓝（按钮蓝在卡片上只有 3.62）。

## 3. 字体排印规则

环境里没有 SF Pro 时，回退顺序是：`-apple-system`、`Helvetica Neue`、`PingFang SC`、`Noto Sans SC`。20px 及以上用 Display 的字距和字重，19px 及以下用 Text。

| 层级 | 类名 | 规格 |
| --- | --- | --- |
| 页面大标题 | `.h-page` | 34 / 600 / 1.12 / −0.022em |
| 区块标题 | `.h-sec` | 22 / 600 / 1.2 / −0.016em |
| 卡片标题 | `.h-card` | 16 / 600 / 1.35 |
| 正文 | `.t-body` | 15 / 400 / 1.6 |
| 说明 | `.t-cap` | 13 / 400 / 1.45 |
| 注脚 | `.t-mic` | 12 / 400 / 1.4 / −0.01em |
| 按钮 | `.btn` | 17 / 500 |
| 数字 | `.num` | 等宽数字 |

负字距用在标题和按钮上。金额、积分、进度用等宽数字。

## 4. 组件样式

### 按钮

| 变体 | 默认 | 按下 | 禁用 |
| --- | --- | --- | --- |
| 主按钮 `.btn-p` | `#0071e3` + 白字 | `#0066cc` | `#3a3a3c` + `#8e8e93` |
| 次按钮 `.btn-s` | `#3a3a3c` + `#f5f5f7` | `#636366` | 同上 |
| 白底 `.btn-w` | `#2c2c2e` + 浅字 | `#3a3a3c` | 同上 |
| 反色 `.btn-d` | 白底黑字 | `#e5e5ea` | 同上 |
| 危险 `.btn-danger` | `#ff453a` + 白字 | — | 同上 |
| 文字 `.btn-g` | `#98989d` | `#f5f5f7` | — |

高度 50 / 44 / 36，圆角 14 / 14 / 10。一屏只有一个蓝色实心按钮。聚焦环 `0 0 0 3px rgba(0,113,227,.45)`，只在键盘聚焦时出现。

### 输入、选择、列表

- 输入框：`#2c2c2e` 底，1px 发丝线。聚焦时蓝色描边加一层蓝色浅底。错误时红色描边，下面写原因。
- Chip：未选中是浮起灰，选中是蓝色实心白字。
- 分段控件：轨道 `#3a3a3c`，选中 `#636366` 白字。
- 列表：`#1c1c1e`，行高至少 52，分隔线是发丝白。按下变成纯黑。
- 复选选中为蓝色实心。

### 面板与提示

- 底部面板和弹窗用 `#3a3a3c`，顶部圆角 24，遮罩 `rgba(0,0,0,.64)`。
- TabBar 和底部 Dock 用 `rgba(28,28,30,.86)` 加 `blur(20px)`，模仿磨砂导航。
- Toast 和气泡是 `#3a3a3c` 白字。错误 Toast 用红色底。
- 返回箭头、文字链接、价格用 `#2997ff`，不用按钮蓝。

## 5. 布局原则

- 画布 390×812。状态栏 47，导航 44（右侧留给 87×32 胶囊），TabBar 84，底部安全区 34。
- 间距仍是 4 的倍数：4、8、12、16、20、24、32、48。页面左右边距 20。
- 圆角：进度条 3，时长标 6，小按钮 10，按钮和输入 14，卡片 16，播放器 20，面板 24。
- 一级页面标题左对齐、34px。二级页面用 17px 导航标题加蓝色返回。
- 视频卡片双列。封面是深灰，不是暖色纸。

## 6. 层级与投影

| 层级 | 表面 |
| --- | --- |
| 0 页面 | `#000000` |
| 1 卡片 / 列表 | `#1c1c1e` |
| 2 输入 / 浮起 | `#2c2c2e` |
| 3 次按钮 / 面板 / Toast | `#3a3a3c` |
| 4 磨砂条 | `rgba(28,28,30,.86)` + 模糊 |

不给卡片和按钮加投影。手机外框在画板上只留 1px 白线，方便在黑底上把屏幕分开。

## 7. Do's 与 Don'ts

要做：

- 蓝色只给下一步：一个实心按钮，加上链接和价格。
- 失败要写原因、下一步、积分去向。
- 金额写清扣多少、从哪个池扣、扣完剩多少。
- 状态用颜色、图标、文字一起表达。

不要做：

- 不要在 `#0a84ff` 或 `#2997ff` 上放白字小按钮。实心按钮只用 `#0071e3`。
- 不要把 `#0071e3` 当深底上的小字。链接用 `#2997ff`。
- 不要用投影、渐变、衬线、暖色纸底。
- 不要用绿和红做装饰。

## 8. 响应式行为

- 基准宽度 390。375 时双列卡片变窄，字号不变。
- 导出的单页在 480px 以下铺满屏幕，桌面居中并带翻页。
- 点击热区至少 44×44。底部操作避开 Home Indicator。
- 过渡 180ms。`prefers-reduced-motion` 时关掉。
