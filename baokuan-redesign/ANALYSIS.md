# 爆款视频 AI 生成 · 原型分析

分析对象：[figma-board.html](https://baokuan-deliverables.app.workbuddy.host/figma-board.html)，
微信小程序，23 屏，390 × 812，黑紫主题。

## 1. 产品一句话

上传商品图 → AI 识别商品 → 选一条同类爆款参考视频 → 花积分生成“商品换成你的”同款带货视频。
商业模式是积分制：1 元 = 100 积分，优惠价 18 积分/秒（原价 66 划线），新人赠送 500。

## 3. 原型存在的问题

### 3.1 流程断点（阻断性）

| # | 位置 | 问题 |
| --- | --- | --- |
| P1 | 08 → ? | 点「确认生成」后没有落地页。用户不知道任务提交成功了没有、要等多久、能不能离开。 |
| P2 | 16 → ? | 「确认支付」后没有成功 / 失败 / 取消的结果页，积分是否到账无法确认。 |
| P3 | 05 底部 | 「手动上传同款类型的参考」入口存在，但没有对应页面。 |
| P4 | 21 | 协议列表可点，但没有协议详情页。01 登录页的《用户协议》《隐私政策》链接同样落空。 |
| P5 | 15 | 「联系客服」入口存在，但没有页面。 |
| P6 | 15 / 17 | 屏幕标题写着「月产能 / 裂变」，积分明细里也有「邀请好友奖励 +500」，但全原型没有邀请页，也没有月产能展示。 |

### 3.2 信息缺失

| # | 位置 | 问题 |
| --- | --- | --- |
| I1 | 08 | 标题叫「赠送积分抵扣」，但弹框只写「剩余 1,190」，**没说明扣的是赠送池还是充值池**。17 积分明细明确是双池记账，这里必须对齐。 |
| I2 | 09 | 余额 120、需要 270，只给了「去充值」。没有告诉用户**还差 150**，也没有推荐最小够用的档位（首充 ¥10）。 |
| I3 | 16 | 顶部只显示「充值积分余额 690」，**赠送池 500 不见了**，与 15 我的页「剩余 1,190」口径冲突。 |
| I4 | 10 | 「生成中」卡片没有进度和预计时间；「作品已过期」没有说明保留期限。 |
| I5 | 14 | 屏名是「作品卡操作面板」，画的却是「生成失败」弹框，真正的作品操作面板缺失。 |

### 3.3 视觉与交互

| # | 问题 |
| --- | --- |
| V1 | 黑底 + 紫色渐变 + 发光按钮，整体“科技感”强，但缺少带货工具需要的**信任感**；且大面积纯黑在户外强光下可读性差。 |
| V2 | 全部图标与商品缩略图使用 emoji（👕🧵🛏️💎📋），跨机型渲染不一致，精致度不足。 |
| V3 | 10 作品列表每张大卡都平铺「下载 / 分享 / 删除」三个按钮，8 张卡就有 24 个按钮，噪音大，且「删除」离「下载」太近，误触风险高。 |
| V4 | 价格信息（270 积分、990 划线）在不同页面样式不统一：有时紫色、有时绿色、有时白色。 |
| V5 | 次要文字大量使用低对比灰紫色，多处低于 4.5:1。 |

## 4. 缺失的页面与状态（本次补充）

优先级：**P0** 不补就断流程；**P1** 影响转化或信任；**P2** 体验完善。

### 4.1 新增页面（7）

| 编号 | 页面 | 优先级 | 解决的问题 |
| --- | --- | --- | --- |
| 09a | 已提交 · 生成进度 | P0 | P1。分步进度 + 预计时长 + 积分冻结说明 + 订阅完成通知 |
| 05b | 参考视频详情 | P1 | 选模板前先看原视频和复刻点，减少“生成完才发现不对”的浪费 |
| 05c | 手动上传参考视频 | P0 | P3 |
| 15a | 邀请好友 | P1 | P6。落地「裂变」，规则、战绩、分享 |
| 15b | 联系客服 | P1 | P5 |
| 21a | 协议详情 | P0 | P4（登录合规必需） |
| 16a | 支付成功 | P0 | P2 |

### 4.2 新增状态（10）
