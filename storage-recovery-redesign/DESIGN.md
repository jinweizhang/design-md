## 4. 组件

### 4.1 盘位卡片（Disk Row）

- 左侧：盘位号 + 小图标
- 中间：型号 | 容量 | 类型
- 右侧：状态 Badge（故障=红，新盘=蓝，健康=绿）

### 4.2 风险横幅（Critical Banner）

- 仅当「替换盘已有数据」显示
- 背景 `--danger-bg`，边框 `--danger-border`
- 左侧警告图标，标题 + 一句说明
- 必须搭配 Checkbox：「我了解替换盘上的数据将被永久删除」

### 4.3 注意事项（Notice）

- 背景 `--warning-bg`，文字 `--warning`
- 列表化：勿关机、勿拔盘、预计耗时

### 4.4 密码区

- 标签写明账号名
- 聚焦环 `--primary`
- 显示/隐藏密码 toggle

### 4.5 按钮

- 次要：`取消` — 灰底 `#F3F4F6`，文字 `#2563EB`
- 主要：`开始同步` — 禁用态 40% 透明度，满足条件后启用

## 5. 布局（单页增强版）

```
Modal 560px 宽
├─ Header: 标题 + 关闭
├─ Context: 存储池名称 + RAID 模式（一行 meta）
├─ Bay Card: 盘位 01 可视化条
├─ Disk Compare: 故障盘 | 箭头 | 替换盘（两列）
├─ Critical Banner（条件显示）
├─ Notice 列表
├─ Password
└─ Footer: 取消 | 开始同步（disabled 逻辑）
```

---

## 6. 交互规则

1. `开始同步` disabled 当：密码为空 **或**（有数据且未勾选确认）
2. `Esc` → 等同取消（恢复未开始时）
3. 提交中：主按钮 loading，禁止关闭
4. 密码错误：输入框下方红色提示，不关闭弹窗
