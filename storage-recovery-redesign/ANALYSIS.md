# 存储恢复弹窗 — 界面逻辑分析与重设计

## 一、当前界面在做什么

这是一个 **NAS / 存储池故障盘替换后的最终确认弹窗**，场景如下：

1. 系统检测到 **盘位 01** 上的硬盘故障（`Mock Bay Disk 03`）。
2. 用户已插入一块新盘（`Mock Bay Disk 01`），系统识别到该盘 **已有数据**（`已有数据`）。
3. 用户需要输入管理员账号 `everzone` 的密码，确认启动 **存储恢复**（将新盘纳入当前存储并重建/同步数据）。
4. 恢复过程中会 **清空替换盘上的全部数据**，且不可中断。

本质：**高风险的破坏性操作 + 身份验证 + 单步确认**。

---

## 二、用户心智模型 vs 系统行为

| 用户可能以为 | 系统实际行为 |
| --- | --- |
| 「恢复」= 把旧盘数据救回来 | 更可能是 RAID/存储池重建，用池内其余盘数据同步到新盘 |
| 替换盘有数据也许能保留 | 明确会 **清除替换盘全部数据** |
| 输密码就能开始 | 未说明恢复时长、能否取消、失败后怎么办 |
| 盘位 01 只跟这一块盘有关 | 未展示存储池名称、冗余模式、影响范围 |

当前文案只强调了「别关机、别拔盘」，但没有解释 **恢复是什么、要多久、失败会怎样**。

### 隐含的业务逻辑（推断）

```
故障检测 → 用户换盘 → 系统识别新盘 → 弹出本弹窗
    → 密码校验 → 开始恢复任务（后台）→ 进度/完成通知
```

## 四、现有设计的问题

### 4.1 信息层级

- **「已有数据」** 与故障/替换信息同级展示，容易被扫读忽略；这是二次数据丢失风险点。
- 警告区在密码框 **下方**，用户可能先输入密码再看到完整风险。
- 缺少 **存储池上下文**（池名、RAID 类型、剩余健康盘数量）。

### 4.2 交互与安全

- 「开始恢复」未与密码有效性绑定（截图中密码为空仍可点？）。
- 无 **二次确认**（尤其对「替换盘已有数据将被清除」）。
- 关闭 `×` 与「取消」行为未区分（是否等同放弃本次换盘流程？）。

### 4.3 文案与概念

- 「存储恢复」易与 **备份还原 / 文件恢复** 混淆；更准确可能是「重建存储」或「替换故障盘并同步数据」。
- 未说明 **预计耗时**、**进行中能否取消**、**失败回滚策略**。

### 4.4 视觉

- 故障盘与替换盘无 **状态色区分**（红/绿或灰/蓝）。
- 信息区与警告区都是大块色块， **风险梯度不清晰**（「已有数据」应比通用警告更醒目）。

---

## 五、重设计目标

1. **先理解再授权**：上下文 → 风险 → 确认勾选 → 密码 → 操作。
2. **风险分级**：通用注意事项 vs 「替换盘数据将被永久删除」。
3. **可预期**：预估时间、进行中状态、失败指引入口。
4. **防误触**：主按钮默认禁用；有数据盘需额外勾选；可选输入确认词。

## 六、重设计信息架构（三步内完成）

### 方案 A：单页增强（改动小）

在现有单弹窗内重组区块顺序，见 `index.html` 默认视图。

### 方案 B：向导式（推荐用于生产）

| 步骤 | 内容 | 主操作 |
| --- | --- | --- |
| 1 核对 | 盘位、故障盘、替换盘、存储池、RAID | 下一步 |
| 2 风险 | 分级警告 + 「已有数据」强制勾选 | 下一步 |
| 3 确认 | 密码 + 预估时间 | 开始恢复 |

恢复开始后切换为 **进度弹窗/页**，非本弹窗范畴但应在 PRD 中串联。

## 七、状态与边界情况

| 状态 | UI 处理 |
| --- | --- |
| 替换盘无数据 | 隐藏「已有数据」横幅与额外勾选 |
| 替换盘容量 < 故障盘 | 阻断操作，说明容量不足 |
| 替换盘容量更大 | 提示仅使用所需容量，余量未纳入池（若业务如此） |
| 密码错误 | 行内错误，不清空盘位信息 |
| 恢复进行中 | 禁用关闭；仅允许查看进度 |
| 多块盘同时故障 | 不应进入本弹窗，应提示联系支持 |

## 八、文案建议（中文）

| 原文案 | 建议 |
| --- | --- |
| 存储恢复 | **替换故障盘并同步数据**（副标题：将新硬盘纳入当前存储池） |
| 故障硬盘 | **已故障的硬盘**（红色状态标签） |
| 替换硬盘 | **新插入的硬盘**（蓝色状态标签） |
| 已有数据 | **检测到已有数据 — 同步时将永久删除** |
| 开始恢复 | **开始同步** 或 **确认替换并开始重建** |

## 九、验收标准

- [ ] 用户在未读风险前不会误点主按钮

- [ ] 展示存储池名称与 RAID/冗余模式
- [ ] 主按钮依赖：密码有效 + 风险勾选（有数据时）
- [ ] 提供预计耗时与帮助链接
- [ ] 键盘：Esc = 取消，Enter = 不直接提交（防误触）
