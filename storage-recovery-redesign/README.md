# 存储恢复弹窗重设计

NAS「故障盘替换 / 存储恢复」确认弹窗的逻辑分析与 UI 重设计。

## 文件

| 文件 | 说明 |
| --- | --- |
| `ANALYSIS.md` | 当前界面业务逻辑、问题诊断、重设计目标与验收标准 |
| `DESIGN.md` | 重设计视觉规范（色彩、组件、交互规则） |
| `index.html` | 可交互 HTML 原型（本地打开即可预览） |

## 预览

在浏览器中打开 `index.html`。演示密码为 `demo`（用于模拟提交成功）。

左下角按钮可切换「替换盘已有数据 / 无数据」两种场景。

## 核心改动摘要

1. 标题改为「替换故障盘并同步数据」，避免与备份还原混淆
2. 补充存储池、RAID 模式、预计耗时等上下文
3. 故障盘 vs 新盘左右对比，状态色区分
4. 「已有数据」独立红色横幅 + 强制勾选确认
5. 「开始同步」仅在密码有效且风险确认后启用
